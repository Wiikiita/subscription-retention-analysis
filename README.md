# Subscription Retention Analysis

Independent data analytics portfolio project using public ecommerce transaction data.

## Objective

Analyse customer transaction behaviour to measure repeat purchase and cohort retention, identify churn-risk segments, and propose retention actions that could be evaluated through experimentation.

## Planned analysis

- Data quality checks and transaction cleaning
- Customer-level features: first and last purchase, order frequency, spend and recency
- Cohort retention analysis
- Repeat-purchase and churn-risk metrics
- Behavioural customer segmentation
- Funnel analysis from first purchase to repeat purchase
- Python visualisations and SQL/BigQuery-style analytical queries
- A hypothetical A/B-test measurement plan for a retention initiative

## Tools

Python · pandas · SQL · BigQuery SQL syntax · Jupyter Notebook · matplotlib · seaborn

## Data

The analysis will use public ecommerce transaction data. It does not contain or use any data, files, queries, dashboards or confidential information from Nord Security or any current or former employer.
